CloudPath Analyzer
Phase 6-2 · HCL / Plan / AWS Inventory / Packet Trace

인프라 구성 입력 · 구조도 교체

같은 루트 모듈의 .tf 파일(최대 50개) 또는 Terraform Plan JSON 또는 AWS Inventory JSON 한 개를 선택하세요 (합계 5 MiB). 성공 시 기존 입력 전체를 교체합니다. Packet Trace의 결과 JSON 추가와는 다른 기능입니다. 배포하지 않으며 파일은 영구 저장하지 않습니다.

현재 입력 파일 및 지원 제한

      HCL의 Module 확장, 변수/함수 평가, tfvars, state, override는 미지원. Plan JSON은 확정 ID 관계를 표시하며 제한된 직접 IPv4 구성만 통신 판정을 지원합니다. 표현식 참조 후보는 실제 연결을 의미하지 않습니다. Plan에는 비밀값이 평문으로 포함될 수 있으므로 로컬에서만 취급하세요.

      구성 입력 실패 · 분석 화면 초기화

      선택한 파일은 적용되지 않았거나 적용 여부를 확인하지 못했습니다. 이전 구조도와 Packet Trace를 숨겼습니다.

      위에서 올바른 구성 파일을 다시 선택하세요. 이전 서버 구성을 확인하려면 ‘현재 서버 구성 다시 불러오기’를 누르세요. 다시 불러오면 저장하지 않은 화면 분석 결과는 사라질 수 있습니다.

      구성 파일 처리 실패

      기존 분석 화면은 숨겨졌습니다. 확인 후 올바른 파일을 다시 선택하세요.

      리소스 상세

      왼쪽 구성도에서 리소스를 선택해 주세요.

      CloudPath Analyzer · Terraform 구성 파일로 생성한 논리 그래프입니다. 실제 AWS 리소스를 생성하거나 조회하지 않았습니다. 구성 정보가 불완전하면 연결을 임의로 보완하지 않습니다.
      Packet Trace · 정적 구성 예측 — 실제 패킷 캡처가 아닙니다. 구조도 강조는 입력 파일 지문이 일치하는 경우에만 허용합니다. 결과 자체의 진위는 검증하지 않습니다. PASS는 실제 서비스 응답을 보장하지 않습니다.
      요청 및 응답 흐름
      새 통신 분석 또는 저장된 분석 결과를 선택하세요. 구성 파일 교체는 위 인프라 구성 입력에서 수행합니다.

      새 통신 시나리오 분석

      현재 Terraform 입력 구성의 명시적 IPv4 주소만 선택 가능합니다. 실제 패킷을 보내지 않습니다.

      분석 JSON을 선택하세요.
